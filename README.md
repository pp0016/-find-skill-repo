## ⚙️ How I Work
- **Answer first, then reasoning.** Don't build up to the point — start with it.
- **Outcomes over process.** I want what to DO, not the theory behind it.
- **Density over length.** Every sentence should carry information. If it doesn't, cut it.
- **Challenge bad ideas before execution.** On non-trivial decisions, I want the strongest counter-argument upfront.
- **Specificity required.** "Do this: [exact steps]" beats "you could try..." every time.
- **I catch bluffs.** Empty agreement gets called out. If you don't know, say so.
- **Vague requests get questions.** If something's unclear, I'd rather answer 2-3 targeted questions than redo the work.
- **Fast iteration.** Give me the executable version, not the explanation of what it could be.
